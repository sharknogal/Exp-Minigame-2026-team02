# 특수공 추가 피해의 게이지 충전 비율 조정

공의 공격력은 그대로 두고 **추가 피해로 게이지가 얼마나 빨리 차는지** 조정할 수 있다. 새 설정의 기본값 **100%는 기존 동작을 보존하는 값**이다. 팀의 최종 밸런스 권장값을 뜻하지 않는다.

## Unity에서 바꾸는 곳

1. Unity의 **Project → Assets → _Project → Data**에서 [BallGaugeBalance.asset](../Assets/_Project/Data/BallGaugeBalance.asset)을 선택한다.
2. **Inspector → Additional damage → gauge (%)** 아래에서 바꿀 항목에 `0`~`100` 사이 정수를 입력한다. `Explosion`은 폭발, `Electric`은 감전, `Horizontal Laser`와 `Vertical Laser`는 가로·세로 레이저, `Cross Laser`는 십자 레이저, `Fire`는 화염 추가 피해다. 십자 레이저의 두 방향에는 모두 `Cross Laser Percent`가 적용된다.
3. [BallLaunchPlaytest 씬](../Assets/_Project/Scenes/BallLaunchPlaytest.unity)에서 Play를 누르고 해당 공으로 블록을 맞힌다. 값을 바꾸면 **다음 추가 피해부터** 새 비율을 읽는다. 화염을 이미 예약했더라도 아직 들어가지 않은 화염 피해에는 새 비율이 적용된다. 이미 들어간 충전량은 바뀌지 않는다.

다른 씬에서 값이 반영되지 않으면 `BallEffectController` 컴포넌트의 **Gauge Balance** 칸을 확인한다. 비어 있으면 여섯 효과 모두 100%로 동작한다. 같은 자산을 연결한 씬은 같은 설정을 사용한다.

## 수치를 읽는 방법

아래는 **추가 피해로 실제 블록 체력이 10 줄고**, 이전 소수 잔량이 없는 경우다.

| 설정 | 이번에 게이지에 더하는 값 | 발사 중 보관하는 소수 잔량 |
|---:|---:|---:|
| 0% | 0 | 0 |
| 25% | 2 | 0.50 |
| 50% | 5 | 0 |
| 100% | 10 | 0 |

25%에서 같은 추가 피해를 두 번 주면 첫 번째는 `+2`, 두 번째는 이전 잔량을 합쳐 `+3`, 합계는 `+5`다. **한 번의 발사에 참여하는 모든 공과 추가 효과가 소수 잔량을 공유한다.** 발사가 끝나면 1 미만의 잔량은 버린다. 공유 게이지에 이미 반영한 정수는 기획대로 다음 턴에도 유지한다.

피해 10을 요청해도 블록 체력이 3만 남았다면 계산 기준은 3이다. 또 **모든 공의 직접 피해**는 이 설정을 쓰지 않는다. 실제 체력이 10 줄면 직접 적중은 `+10`, 충전공의 직접 적중은 `+20`이다. 따라서 폭발을 0%로 바꿔도 폭발공이 처음 맞힌 블록의 직접 피해는 계속 충전된다.

## 실험값과 팀 공유값 구분

**Play 중 Project의 자산을 편집한 값은 Play 종료 후에도 남을 수 있다.** 시험만 하려면 Play 전에 Project 창에서 자산을 선택해 `Ctrl+D`로 복제한다. Play 중 테스트 씬의 `BallEffectController → Gauge Balance`에 **복제본**을 연결하고 복제본의 수치를 조정한다. 원본을 직접 시험했다면 기존 여섯 값을 먼저 기록하고 종료 후 복구한다. 팀에 반영할 때는 합의한 값만 원본 자산에 적용한다.

동작 검증은 **Play → Tools → Brick Breaker → Test Additional Gauge Balance (Play)** 로 실행한다. 잠시 뒤 Console에 `PASS: 10 passed, 0 failed.`가 나오면 모두 통과다. 이 검증은 임시 보드와 메모리상의 설정을 사용하며 팀의 밸런스 자산을 변경하지 않는다.
